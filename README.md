# PDF App (nome provisório) — versão web

Organizar, compactar, dividir e extrair texto de PDFs. Funciona no navegador e pode ser instalado (Chrome/Edge) para uso off-line.
Os arquivos são processados no próprio computador e **não são enviados** para a internet.

Este repositório contém apenas o site já compilado. Uso interno; direitos reservados © Felippe Alvarez.
Componentes de terceiros: tesseract.js e Tesseract OCR (Apache-2.0), dados de idioma tessdata_fast (Apache-2.0), lopdf (MIT), hayro (Apache-2.0/MIT), image (MIT/Apache-2.0).
